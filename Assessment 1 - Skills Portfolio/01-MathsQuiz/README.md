Exercise 1 – Math Quiz

Description

This is a python based math Quiz application with Tkinter. It can be used to practice questions of addition and subtraction at various levels of difficulty.

The application creates random questions, validates the answer entered by the user, computes the score and shows the final score obtained by the user.

Features

3 levels of difficulty: Easy, Moderate, and Advanced.
- Single numbers (those under 10) are used in EASY mode.
The numbers used in the moderate mode are in the double digits.
In advanced mode the numbers used are 4 digits.
- There are 10 random questions on each quiz.
- Questions include addition and subtraction.
- Users will be given two chances per question.
All correct answers get 10 points for the first time.
- Correct answers on the second attempt earn 5 points.
If the student gets the questions wrong on both attempts, he or she receives no points for the questions.
The final score is worked out of 100.
- The rank is shown according to the final score.
- Users will be able to replay the quiz once completed.

 How to Run

Open the mathsquiz folder in VS Code.
Ensure that python 3 is installed.
Open `main.py`.
In terminal run the following command:

bash
python main.py

How to Use

1. Start the application.
2. Click on Easy, Moderate or Advanced.
3. Read the math question displayed.
4. Enter your answer and submit it.
5. If player responds to question 1 incorrectly, repeat that question.
6. Complete all 10 questions.
7. See your final rank and score.
8. Play again or end.

| Attempt | Points |
| First correct attempt | 10 |
| Second correct attempt | 5 |
| Both attempts incorrect | 0 |
